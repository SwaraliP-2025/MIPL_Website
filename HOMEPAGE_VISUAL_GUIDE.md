## Section Details

### 1. Hero Section
**Visual Elements:**
- Full-screen height with animated network background
- Centered content with gradient text
- Badge with shield icon at top
- Large bold headline (4xl-7xl font size)
- Descriptive sub-headline
- Two prominent CTA buttons
- Floating animated icons (Lock, Network) on desktop
- Scroll indicator at bottom

**Colors:**
- Primary blue for CTAs and accents
- White/dark text based on theme
- Gradient overlays for depth
- Glass effect on badge

**Animations:**
- Fade in and slide up on load
- Floating icons with CSS animation
- Pulsing scroll indicator
- Hover effects on buttons

### 2. Stats Section
**Visual Elements:**
- 4 statistics in a grid
- Large gradient numbers (5xl-7xl)
- Animated counter effect
- Subtle network background
- Centered layout

**Layout:**
- Mobile: 2 columns
- Desktop: 4 columns
- Equal spacing between items

**Animations:**
- Numbers count up on scroll into view
- Fade in effect
- Staggered delays

### 3. Services Grid
**Visual Elements:**
- Grid of service cards
- Icons for each service
- Hover effects with scale
- Glass-card design

**Layout:**
- Mobile: 1 column
- Tablet: 2 columns
- Desktop: 3 columns

### 4. Client Logos Section
**Visual Elements:**
- Section title and description
- Grid of logo cards
- White background cards for contrast
- Client names below logos
- Bottom text about client count

**Layout:**
- Mobile: 2 columns
- Tablet: 3 columns
- Desktop: 5 columns

**Hover Effects:**
- Scale up (110%)
- Opacity increase
- Smooth transitions

**Features:**
- Fallback text if image fails
- Responsive sizing
- Proper spacing

### 5. Testimonials Section
**Visual Elements:**
- Section title and description
- 3 testimonial cards
- Quote icons
- Glass-card design
- Author details with company

**Layout:**
- Mobile: 1 column (stacked)
- Desktop: 3 columns (side by side)

**Card Structure:**
- Quote icon at top
- Testimonial text (justified)
- Border separator
- Author name (bold)
- Role (muted)
- Company (primary color)

**Animations:**
- Fade in on scroll
- Staggered delays (0.1s each)
- Hover shadow effect

### 6. Trava Section
**Visual Elements:**
- TRAVA product information
- Logo and description
- Call to action

### 7. CTA Section
**Visual Elements:**
- Final call to action
- Large button
- Centered layout

## Responsive Breakpoints

### Mobile (< 768px)
- Single column layouts
- Stacked buttons
- Smaller font sizes
- 2-column client logos
- 1-column testimonials
- Hidden floating icons

### Tablet (768px - 1023px)
- 2-3 column layouts
- Side-by-side buttons
- Medium font sizes
- 3-column client logos
- 2-3 column testimonials

### Desktop (1024px+)
- Full multi-column layouts
- Large font sizes
- 5-column client logos
- 3-column testimonials
- Floating icons visible
- Full animations

## Color Scheme

### Light Mode
- Background: White/Light gray
- Text: Dark gray/Black
- Primary: Blue (#0066CC)
- Cards: White with subtle shadow
- Borders: Light gray

### Dark Mode
- Background: Dark gray/Black
- Text: White/Light gray
- Primary: Blue (#0066CC)
- Cards: Dark with glass effect
- Borders: White/10% opacity

## Typography

### Headings
- Hero: 4xl-7xl (48px-72px)
- Section titles: 3xl-4xl (36px-48px)
- Card titles: xl-2xl (20px-24px)

### Body Text
- Hero sub-headline: lg-xl (18px-20px)
- Section descriptions: base-lg (16px-18px)
- Card content: sm-base (14px-16px)

### Font Weights
- Headlines: Bold (700)
- Titles: Semibold (600)
- Body: Regular (400)
- Muted: Regular (400) with opacity

## Spacing

### Section Padding
- Mobile: py-12 (48px)
- Desktop: py-16 to py-24 (64px-96px)

### Container
- Max width: 1280px
- Padding: px-4 to px-8 (16px-32px)

### Grid Gaps
- Mobile: gap-4 to gap-6 (16px-24px)
- Desktop: gap-8 to gap-12 (32px-48px)

## Animations

### Scroll Animations
- Fade in: opacity 0 → 1
- Slide up: y: 20-30px → 0
- Duration: 0.6-0.8s
- Easing: ease-out

### Hover Animations
- Scale: 1 → 1.05-1.1
- Shadow: subtle → prominent
- Duration: 0.3s
- Easing: ease-in-out

### Counter Animations
- Duration: 2s
- Steps: 60
- Easing: linear

## Accessibility

### ARIA Labels
- Navigation landmarks
- Button descriptions
- Image alt text
- Breadcrumb navigation

### Keyboard Navigation
- Tab order logical
- Focus states visible
- Skip to content link

### Color Contrast
- WCAG AA compliant
- Sufficient contrast ratios
- Readable in both themes
