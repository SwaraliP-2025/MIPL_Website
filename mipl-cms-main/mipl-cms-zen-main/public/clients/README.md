# Client Logos Folder

This folder contains client logos displayed on the homepage in the "Trusted by Leading Organizations" section.

## Required Logo Files

Please add the following logo files to this folder:

1. `hpcl-logo.png` - Hindustan Petroleum Corporation Limited
2. `jnpt-logo.png` - Jawaharlal Nehru Port Trust
3. `ascdcl-logo.png` - Aurangabad Smart City Development Corporation Limited
4. `iocl-logo.png` - Indian Oil Corporation Limited
5. `bnp-logo.png` - BNP Paribas
6. `nayara-logo.png` - Nayara Energy
7. `mrpl-logo.png` - Mangalore Refinery and Petrochemicals Limited
8. `gujarat-police-logo.png` - Gujarat Police
9. `sdb-logo.png` - Surat Diamond Bourse
10. `maharashtra-logo.png` - Maharashtra Government

## Image Specifications

- **Format:** PNG (with transparent background preferred)
- **Size:** Recommended height of 100-150px
- **Aspect Ratio:** Maintain original logo proportions
- **Quality:** High resolution for crisp display
- **Background:** Transparent or white background

## Notes

- Logos will be displayed in grayscale by default
- On hover, logos will show in full color
- If a logo file is missing, the client name will be displayed as text instead
- All logos should be properly licensed for use on your website

## Component Location

The ClientLogos component is located at: `src/components/home/ClientLogos.jsx`

To add or remove clients, edit the `clients` array in that file.
